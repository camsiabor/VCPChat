## 快速概念词汇表 | Quick Glossary

| 术语 Term | 说明 Description |
|-----------|-----------------|
| **VCP** | Variable & Command Protocol — AI 工具调用中间层协议 / AI tool-call middleware protocol |
| **VCPToolBox** | VCP 后端服务器，VCPChat 的配套后端 / VCP backend server, companion to VCPChat |
| **Agent** | 一个具名的 AI 角色配置（含系统提示词、模型参数、头像等）/ A named AI persona config (system prompt, model params, avatar, etc.) |
| **Topic** | 一个 Agent 或群组下的独立聊天会话 / An independent chat session under an Agent or Group |
| **Group** | 多 Agent 群聊配置 / Multi-Agent group chat configuration |
| **Flowlock** | 心流锁 — 让 Agent 自动续写的持续对话模式 / Continuous auto-reply mode for Agents |
| **Canvas** | 协同代码/文档编辑器（内嵌 CodeMirror 5）/ Collaborative code/doc editor (CodeMirror 5 embedded) |
| **IPC** | Electron 进程间通信（ipcMain / ipcRenderer / contextBridge）/ Electron inter-process communication |
| **Distributed Server** | VCPDistributedServer — 内嵌于 VCPChat 的轻量级分布式节点服务器 / Lightweight distributed node server embedded in VCPChat |
| **AppData** | 项目内数据目录（`./AppData/`），存储设置、Agent 配置、聊天历史等 / In-project data dir storing settings, agent configs, chat history |
| **SoVITS TTS** | SoVITS 语音合成模块 / SoVITS text-to-speech module |
| **RAG** | Retrieval-Augmented Generation — 记忆库检索增强 / Memory retrieval-augmented generation |
